# CircleSwitcher v2.0.0 (GitHub Actions CI Ready)

## Cách build tự động trên GitHub
1. Tải toàn bộ nội dung bên trong thư mục `CircleSwitcher-2.0.0/` lên repository GitHub của anh (đảm bảo thư mục `.github/workflows/build.yml` nằm ngay ở thư mục gốc của repo).
2. Vào tab **Actions** trên GitHub -> chọn workflow **Build CircleSwitcher 2.0.0 (.deb)** -> bấm **Run workflow** (hoặc tự chạy mỗi khi anh push code).
3. Sau khi build xong (~1–2 phút), kéo xuống phần **Artifacts** ở cuối trang run để tải trực tiếp:
   - `CircleSwitcher-2.0.0-Rootless-deb` (cho iPhone 12 Pro iOS 16.3.1 Rootless / Sileo)
   - `CircleSwitcher-2.0.0-Rootful-deb` (cho iOS 14 Rootful)
